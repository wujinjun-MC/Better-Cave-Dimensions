# AI Policy

## Policy

AI / LLM is prohibited in:
- Generating codes/assets(e.g. icon and .nbt model)/texts(e.g. README) for this datapack
    - Reason:
        - I have to enable "Contains AI-generated content" in "Content disclosures" section of project settings if there are such things generated by AI (and select which kinda things are AI generated) and other players will not see this project if they exclude AI-generated content in "Advanced exclusions"
        - In `Modrinth content rules` 6.2: "No images uploaded to a gallery, icon, description, or any other part of a project page may be created or derived from generative AI output. Any such images may be removed."
- Generating issues or pull requests
    - Reason: Any fixes/requests should be made by actual humans with care and consideration, not by AI.
- i18n / Translation
    - Including "traditional" translator (e.g. translate.google.com) and LLMs

AI / LLM may be used in:
- Code reviewing, bug fixing, and quality suggestion
    - However, any changes must not be generated directly.
        - Example: You can ask AI to check if the code is wrong, but if any problem is spotted, you must write code fixes on your own.

See also:
- [Modrinth content rules](https://modrinth.com/legal/rules) after August 13, 2026 (Section 6)
